# Security

This is an unaudited prototype, unsuitable for funds or sensitive document deployments. No bounty is offered.

Please report a suspected vulnerability privately through GitHub private vulnerability reporting when enabled. If the private-report option is unavailable, open a minimal issue asking for a private reporting channel; do not publish exploit details, keys, private documents or personal data.

Supported code: current default branch. Test/demo networks only. Public Anvil accounts are development fixtures, not secrets, and must never receive real funds.
